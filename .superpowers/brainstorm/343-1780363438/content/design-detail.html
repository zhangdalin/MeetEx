设计规格

✓

尺寸规格

  • 高度: 10px
  • 圆角: 10px (全圆角胶囊形状)
  • 最小宽度: 100px
  • 与设备标签间距: 12px
✓

颜色方案

  • 背景色: #e9ecef (浅灰)
  • 进度条渐变: #0078d4 → #2b88d8 → #0078d4
  • 峰值标记: #106ebe (深蓝)
  • 禁用状态: #999999 (灰色)
✓

动画效果

  • 电平变化过渡: 100ms ease-out
  • 峰值标记衰减: 300ms 后淡出
  • 更新频率: 100ms (与现有 timer 一致)
✓

峰值保持功能

  • 峰值标记宽度: 3px
  • 显示时长: 300ms
  • 衰减方式: 淡出 (opacity 0.8 → 0)
  • 更新逻辑: 新峰值立即刷新位置和透明度

实现方式对比

方案 1: QSS 样式表 (推荐)

  • ✓ 无需自定义控件
  • ✓ 简单易维护
  • ✓ 与 Qt Designer 兼容
  • ✗ 峰值标记需额外 QLabel

方案 2: 自定义控件

  • ✓ 完全自定义绘制
  • ✓ 动画更流畅
  • ✗ 增加代码复杂度
  • ✗ 需要额外测试
