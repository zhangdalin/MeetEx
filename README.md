# MeetEx - 视频会议系统

基于 Qt 的视频会议桌面应用程序。

## 项目说明

MeetEx 是基于 Qt 的视频会议桌面应用程序，目标构建一个完整的企业级视频会议系统。当前文档在功能模块、会议流程和待开发功能上形成了初步需求框架。

## 功能模块

### 1. 用户认证模块
- 账号密码登录
- 手机验证码登录
- 用户注册
- 密码找回
- 第三方登录（预留接口）

### 2. 会议模块
- 快速会议（即时发起）
- 加入会议（输入会议号）
- 预约会议
- 会前设备检测
- 会议控制（静音/视频/共享/录制）

### 3. 录制模块
- 会议录制（本地/云端）
- 录制文件管理
- 录制回放
- 存储空间管理

### 4. 社交模块
- 参会者管理
- 实时聊天
- 举手发言
- 屏幕共享

### 5. 设置模块
- 视频设置（摄像头/分辨率/美颜）
- 音频设置（麦克风/扬声器/降噪）
- 会议设置（入会选项/默认布局）
- 录制设置（存储路径/自动录制）

### 6. 信令与网络模块
- 实时信令通道（WebSocket / WebRTC 信令）
- HTTP API / REST 接口
- 会议房间管理与会话保持
- NAT 穿透与网络适配

### 7. 音视频引擎模块
- 音视频编码/解码
- 自适应码率与带宽控制
- 回声消除、噪声抑制、自动增益
- 视频分辨率/帧率动态调整
- 本地预览与摄像头切换

### 8. 会议管理模块
- 会议室生命周期管理（创建/结束/锁定）
- 角色与权限控制（主持人/嘉宾/观看者）
- 邀请与入会审批
- 预约会议、日程管理、日历同步

### 9. 安全与权限模块
- 传输层加密与会话安全
- 会议密码与访客控制
- 单点登录 / OAuth / SSO预留
- 日志审计与安全行为监控

### 10. 协作与通知模块
- 会议通知/提醒/短信/邮件
- 聊天与群组消息
- 文件传输与共享
- 白板、投票、问卷、实时字幕（预留）

### 11. 质量监控模块
- 网络质量检测
- 会中 QoS 统计
- 参会者音视频质量监测
- 异常告警与恢复机制

### 12. 运维与日志模块
- 运行日志与用户行为日志
- 错误上报与诊断工具
- 日志聚合与分析
- 系统健康检查与版本管理

### 13. 多端与扩展支持
- 插件/扩展机制
- 移动端、Web 端兼容设计预留
- 多语言国际化支持
- 多租户/企业级配置支持

## 待开发功能模块

### 1. 网络通信模块
- 实现实际的网络通信层（HTTP / WebSocket）
- 完成信令通道与实时消息传递
- 支持会议房间创建、加入、离开与会话保持

### 2. 音视频引擎集成模块
- 集成 livekit 音视频会议引擎
- 使用 `thirdparty\livekit` 中的 C++ SDK 接入音视频能力
- 实现音视频连接、媒体流传输与设备管理

### 3. 屏幕共享模块
- 支持跨平台屏幕共享与窗口共享
- 共享权限控制与协作切换
- 优化共享带宽与质量

### 4. 云端录制模块
- 支持云端会议录制与存储
- 录制任务管理与回放入口
- 本地与云端录制策略切换

### 5. 通知与日程模块
- 会议预约通知与提醒
- 日程同步与会议邀请管理
- 短信/邮件/系统通知集成预留

### 6. 多语言与多端模块
- 完善多语言国际化支持
- 规划移动端与 Web 端兼容设计
- 支持多租户和企业级配置

### 7. 角色与权限模块
- 实现会议主持人、嘉宾、参与者权限控制
- 支持入会审批、房间锁定、访客管理
- 控制音视频、屏幕共享、聊天等权限

### 8. 协作与文件共享模块
- 云端白板、文件共享与协作能力
- 实现会议内实时文档和资源传输
- 支持群组消息与协作拓展

### 9. 质量与诊断模块
- 会议质量监测与网络诊断工具
- 会中 QoS 统计与异常告警
- 提供本地诊断和性能分析支持
