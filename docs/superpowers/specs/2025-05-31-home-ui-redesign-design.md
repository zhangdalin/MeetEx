# MeetEx 首页 UI 重设计规格文档

**日期**: 2025-05-31  
**主题**: 首页 UI 重设计 - 腾讯会议风格  
**状态**: 已确认，待实施

---

## 1. 设计目标

将当前 `home.ui` 重新设计为更具视频会议软件特点的布局，参考腾讯会议风格，同时保留所有现有功能。

---

## 2. 整体设计方向

采用 **腾讯会议风格** 布局：
- 左侧导航栏（扩展宽度以显示用户信息）
- 右侧主内容区分上下两部分：
  - 顶部：快速操作区（4个核心功能按钮）
  - 中部：会议列表区

---

## 3. 布局规格

### 3.1 窗口尺寸
- 宽度：900px（从 700px 扩展以容纳会议列表）
- 高度：600px（从 500px 扩展）

### 3.2 左侧边栏
| 属性 | 规格 |
|------|------|
| 宽度 | 200px（从 70px 扩展） |
| 背景色 | #f5f5f5 |
| 右边框 | 1px solid #e0e0e0 |

**边栏内容（从上到下）**:
1. **Logo 区域**（顶部 60px）：应用图标或名称
2. **导航按钮组**（中部）：
   - 账号
   - 会议（默认选中）
   - 通讯录
   - 邮箱
   - 录制
3. **分隔线**
4. **设置按钮**
5. **用户信息卡片**（底部）：
   - 头像（40x40px，圆形）
   - 昵称（单行，超出省略）
   - 账号（小号灰色文字）

### 3.3 快速操作区（顶部）
| 属性 | 规格 |
|------|------|
| 高度 | ~120px |
| 内边距 | 30px 40px |

**4个按钮等宽水平排列**:
- 加入会议
- 快速会议
- 预定会议
- 共享屏幕

每个按钮：
- 尺寸：~140px x 80px
- 图标：48x48px（居中上部）
- 文字：14px，位于图标下方
- 背景：白色
- 边框：1px solid #e0e0e0，圆角 8px
- 悬停：边框变为 #0078d4，背景 #f0f7ff

### 3.4 会议列表区（中部）
| 属性 | 规格 |
|------|------|
| 内边距 | 20px 40px |
| 背景 | 白色 |

**列表分组**：
- 今天
- 明天
- 更晚

**单个会议卡片**:
- 高度：~70px
- 内边距：15px 20px
- 背景：白色
- 边框底部：1px solid #f0f0f0
- 圆角：6px
- 悬停：背景 #fafafa

**卡片内容布局**（从左到右）:
1. **时间区域**（80px 宽）
   - 开始时间 - 结束时间
   - 示例："14:00 - 15:00"
   - 字号：13px，颜色 #333

2. **信息区域**（弹性宽度）
   - 状态标签 + 会议主题（同一行）
     - 状态标签：待开始（灰色）、进行中（蓝色高亮）、已结束（灰色删除线）
     - 会议主题：14px，#333，粗体
   - 会议号（第二行）
     - 格式："会议号: XXX XXX XXX"
     - 字号：12px，颜色 #666

3. **操作区域**（120px 宽）
   - "加入" 按钮（主按钮样式，蓝色）
   - "详情" 按钮（文字按钮，灰色）

### 3.5 空状态
当没有会议时显示：
- 居中布局
- 图标：日历图标（64x64px，颜色 #ccc）
- 主文字："暂无即将开始的会议"（16px，#666）
- 按钮："立即预定会议"（主按钮样式）

## 5. 数据结构需求

会议列表需要以下数据模型：

```cpp
struct MeetingInfo {
    QString meetingId;      // 会议号
    QString topic;          // 会议主题
    QDateTime startTime;    // 开始时间
    QDateTime endTime;      // 结束时间
    MeetingStatus status;   // 状态：Pending/Active/Ended
    // 注意：主持人名称和参会人数不在此版本中显示
};

enum class MeetingStatus {
    Pending,    // 待开始
    Active,     // 进行中
    Ended       // 已结束
};
```

## 6. 交互设计

### 6.1 导航切换
- 点击边栏按钮切换不同页面
- 当前选中项高亮显示（蓝色背景或左边框）
- 仅"会议"页面使用新设计，其他页面保持现有实现

### 6.2 会议列表
- 点击会议卡片进入会议详情
- 点击"加入"按钮直接进入会议（同当前"加入会议"功能）
- 列表支持滚动

### 6.3 快速操作按钮
- 点击后打开对应功能窗口（保持现有行为）
- 悬停时显示视觉反馈

## 8. 实现注意事项

1. **侧边栏宽度变化**：从 70px 扩展到 200px，需要更新 `home.ui` 中所有相关尺寸
2. **新增会议列表组件**：需要创建 QListWidget 或自定义 QWidget 来显示会议列表
3. **数据绑定**：会议列表需要从后端获取数据，当前可先使用模拟数据
4. **用户信息卡片**：需要在 `setUserProfile` 中更新边栏的用户信息展示
5. **图标资源**：确认是否有日历图标，如无需要添加或改用现有图标
